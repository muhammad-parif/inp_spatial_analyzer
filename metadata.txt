about=The INP Vegetation Analysis Plugin is designed to process and analyze vegetation data using Importance Value Index (INP). The plugin calculates Relative Density (KR), Relative Frequency (FR), Relative Dominance (DR), and INP for various vegetation growth stages, including trees, poles, stakes, seedlings, lianas, and understory plants. It can export analysis results to CSV, add calculated attributes to vector data, and generate raster heatmaps to visualize spatial distribution using IDW interpolation. Click here to customize the data naming conventions at the stage level: https://docs.google.com/spreadsheets/d/1Pwo5Hs-0Z4UUl0CKj2GvnmGixT2cVVAWlecih10NOuw/edit?usp=drivesdk. The guidelines can be accessed at the following link: https://drive.google.com/file/d/1SJFC4Vl5N0wtCwlgZxUccL4qvvAaOM4X/view?usp=drivesdk.
