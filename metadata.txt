about=The INP Vegetation Analysis Plugin is designed to process and analyze vegetation data using Importance Value Index (INP). The plugin calculates Relative Density (KR), Relative Frequency (FR), Relative Dominance (DR), and INP for various vegetation growth stages, including trees, poles, stakes, seedlings, lianas, and understory plants. It can export analysis results to CSV, add calculated attributes to vector data, and generate raster heatmaps to visualize spatial distribution using IDW interpolation.
